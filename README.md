# Daghlus Car Sales

Daghlus Car Sales is a modern car sales website demo designed to provide customers with a simple way to explore vehicles and manage their accounts.

## Features

- Modern car sales homepage
- Vehicle listings
- Create account
- User login
- User dashboard
- Account information
- Saved account session
- Logout functionality
- Responsive design
- Mobile-friendly interface

## User Flow

Home → Create Account → Login → Dashboard → Logout

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- GitHub

## Project Purpose

This project demonstrates a complete front-end car sales website experience with account registration, login, dashboard navigation, and logout functionality.

## Disclaimer

This is a front-end demonstration project. Account credentials are stored in the browser for demonstration purposes and should not be used for real customer authentication or sensitive information.
